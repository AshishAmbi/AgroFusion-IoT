About This Project

Smart Agriculture Monitoring System

This dashboard connects to a Firebase Realtime Database to display live readings streamed from an ESP32 microcontroller equipped with soil moisture, temperature, humidity, air quality and pressure sensors. Data updates automatically without a page refresh, and the last 50 readings are retained for trend analysis.

Built entirely with HTML5, CSS3 and vanilla JavaScript — no frameworks required.
